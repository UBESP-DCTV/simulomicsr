   ontology STRONG incompatibile (`LLM_CONTRADICTION_DETECTED`, 4568 cluster).

3. **Audit 4 critically wrong Layer B**: **2/4 risolti, 2/4 residual** (vedi §4).
   I 2 residual sono casi-limite della policy attuale (CHEBI compound con 0
   roles, MeSH UI in branch sterols ma LLM dichiara disease_vs_normal). Sono

4. **HALLUCINATED_OR_FALLBACK = 3.14% (12.278 cluster)**: ID emessi dal LLM ma

5. **`NO_AGENT = 49%`**: cluster senza agent (es. disease/environmental con
   `type=none` o `cell_state=hypoxia`). Niente da risolvere, comportamento
