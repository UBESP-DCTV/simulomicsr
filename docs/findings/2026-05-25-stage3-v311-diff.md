## 6. Bug silente PRE-ESISTENTE scoperto durante TDD S1bis

**Trovato:** durante l'aggiunta del test "MeSH:D016899 Interferon-beta tree D
+ LLM=cytokine_stim --> no override (LLM non disease)", il test ha rivelato
che la policy pre-S1bis avrebbe overridden Interferon-beta cytokine_stim a
small_molecule via LLM_CONTRADICTION_DETECTED (MeSH tree D MEDIUM
small_molecule incompatibile con cytokine_stim).

**Magnitude:** dal diff v3.1 vs v3.1.1, **1735 cluster** sono stati salvati
dalla asymmetric trust su MESH_TREE_D. Tipici pattern affected:
- Citokine MeSH:D016899 Interferon-beta, MeSH:D015415 Biomarkers,
  MeSH:D016207 Cytokines (D12 tree)
- Pathogen MeSH:D006998 Hyperviscosity, MeSH:D005829 Genes (D27 tree)

**Status pre-S1bis:** invisible nei numeri aggregate v3.1 (LLM_CONTRADICTION_DETECTED
4568 includeva ~1735 falsi positivi MeSH tree D). Solo il diff cluster-by-cluster
v3.1 vs v3.1.1 rivela la magnitude.

**Lesson learned:** TDD on edge case (Interferon-beta) ha esposto un bug
silente che impattava O(1000) cluster. Il test "MeSH tree D + LLM=cytokine_stim
--> no override" ora è regression guard.
